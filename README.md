# x86_asm 实验代码
这是阅读《x86汇编语言 从实模式到保护模式》一书时，每一章节的实验代码，包含详细注释。

本仓库适合：
- 正在学习这本书的读者参考
- 想了解 x86 实模式到保护模式切换全过程的爱好者学习
- 从零编写一个最小化操作系统内核入门学习

# 运行环境
## 依赖
需要安装以下工具：

```bash
# Ubuntu/Debian
sudo apt-get install nasm qemu-system-x86
```

- **nasm**：x86 汇编编译器
- **qemu-system-i386**：x86 模拟器，用来运行编译后的镜像

## 运行
进入每个章节文件夹，执行脚本运行：

```bash
cd cXX
sh run.sh
```

Qemu 会启动并显示运行结果。

## 说明
- 原书中代码基于 vga 文本模式输出，直接在 Qemu 中运行即可看到结果
- 每个章节对应书中的内容，代码已经添加了详细注释
- 所有汇编文件编码已转换为 UTF-8，在任何系统上都能正常显示注释
- 第14、15章内核里 1 级和 2 级堆栈的 `shr` 需要写明 `dword`，否则 NASM 2.16 会报 operation size not specified
- 第18章用 `c18/run.sh` 启动。扇区 50 和 100 没有用户程序时，屏幕停在调用门安装成功之后
